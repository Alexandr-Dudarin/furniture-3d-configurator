# Furniture 3D Configurator

Браузерный 3D-конструктор мебели на React, TypeScript и Three.js. Настройте
готовую модель, соберите стол или гардеробную, а затем поделитесь своим вариантом.

**[Открыть демо](https://furniture-3d-configurator-kappa.vercel.app/)** ·
[Документация](docs/README.md) · [План развития](docs/roadmap.md)

[![Проверки проекта](https://github.com/Alexandr-Dudarin/furniture-3d-configurator/actions/workflows/ci.yml/badge.svg)](https://github.com/Alexandr-Dudarin/furniture-3d-configurator/actions/workflows/ci.yml)

## Возможности

- **Каталог:** пять столов, четыре шкафа и пять комодов. Размеры, покрытия,
  а для корпусной мебели — сменные рисунки фасадов и ручки.
- **Конструктор стола:** семь форм столешницы, пять оснований и четыре
  профиля кромки с проверкой совместимости и допустимых размеров.
- **Гардеробные:** прямые, Г- и П-образные сборки. Настройка секций, высот
  полок и штанг, ящиков и дверей. Общие материалы и отдельные покрытия
  корпуса, фасадов и фурнитуры каждой секции.
- **3D-просмотр:** вращение и приближение камеры, открывание дверей и ящиков,
  просмотр наполнения готовых шкафов со скрытыми дверями.
- **Сохранение:** автосохранение в браузере, ссылка на конфигурацию,
  текстовое описание и экспорт текущего вида в PNG.

В прямой гардеробной может быть до 7 секций, в Г- и П-образной — до 21,
включая углы. Угловые модули пока открытые, с полками. Единицы размеров
указаны рядом с полями: сантиметры или миллиметры.

## Попробовать за минуту

1. Откройте [демо](https://furniture-3d-configurator-kappa.vercel.app/).
2. Выберите «Готовые модели», «Собрать стол» или «Гардеробная» и измените
   размер, материал или наполнение. Нажмите на фасад в 3D, чтобы открыть его.
3. Используйте «Копировать ссылку» или «Сохранить вид в PNG» внизу панели.

Ссылка передаёт настройки изделия. Ракурс и положение открытых деталей в неё
не входят; PNG сохраняет текущий вид. Регистрация не нужна. Автосохранение
относится к текущему браузеру и адресу сайта.

## Технологии и устройство

**React 19, TypeScript, Three.js, Vite, Vitest, ESLint.** Сцена написана на
Three.js без React Three Fiber. Ресурсы моделей — GLB/glTF 2.0 и PBR-материалы.

- Готовая модель подключается через GLB и декларативное описание
  `FurnitureDefinition`: размеры, правила изменения деталей, материалы,
  фасады и открывание. Общий контроллер применяет эти правила.
- Геометрия изменяется в физических единицах с сохранением толщины панелей,
  сечения опор и размеров фурнитуры. UV-компенсация удерживает масштаб текстур.
- Настройки и ограничения отделены от React-интерфейса и Three.js-сцены.
  Сохранения и ссылки проходят нормализацию и поддерживают прежние форматы.
- 3D-просмотр и ресурсы моделей загружаются по мере необходимости.
  Кэши ограничены, неиспользуемые ресурсы освобождаются. Неподвижная сцена
  перестаёт перерисовываться после уточнения сглаживания.
- Тесты проверяют состояние, совместимость, геометрию, открывание и реальные
  GLB. GitHub Actions запускает проверки для pull request и `main`.

## Локальный запуск

Используется **Node.js 24** и npm. В корне проекта:

```bash
npm ci
npm run dev -- --host 127.0.0.1
```

Откройте адрес из строки `Local` в терминале, обычно
`http://127.0.0.1:5173/`. Терминал должен оставаться открытым;
`Ctrl+C` останавливает сервер. Ключи API и переменные окружения не требуются.

## Проверки

```bash
npm run lint
npm test -- --testTimeout=60000 --maxWorkers=2
npm run build
npm run check:publication
```

Сборка включает TypeScript и подготовку сайта в `dist/`.
`check:publication` проверяет ссылки на ресурсы, состав загрузки и совпадение
публичных файлов с результатом сборки. Автоматические проверки не заменяют
визуальную проверку WebGL на реальных устройствах.

Для просмотра готовой сборки:

```bash
npm run preview -- --host 127.0.0.1
```

Настройки размещения и CI: [развёртывание](docs/deployment.md).

## Границы текущей версии

Это интерактивный прототип. Он проверяет предусмотренные геометрические
ограничения, но не рассчитывает прочность крепежа, стоимость или производственные
чертежи. Наполнение углов и удобство панели продолжают развиваться.
На мелком рифлении при движении камеры возможен муар; статичный кадр
дополнительно сглаживается.

Дальнейшие этапы, включая рефакторинг состояния и 3D-сборки гардеробной,
описаны в [дорожной карте](docs/roadmap.md).
