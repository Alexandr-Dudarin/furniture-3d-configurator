# Покрытия по фотографиям пользователя

Добавлены 22 сентября 2026 для корпуса и фасадов всех трёх шкафов и пяти комодов.

| ID | Название | Базовый sRGB | Roughness | Референс |
|---|---|---|---|---|
| `board-muted-green` | Тёмно-зелёный матовый | `#4b5748` | 0.58 | `muted-green-reference.png` — «пример фасадов и цвета.png» |
| `board-powder-beige` | Пудрово-бежевый матовый | `#bda99b` | 0.55 | `powder-beige-reference.png` — «пример фасада для шкафа и цвет.png» |

Это визуальное приближение оттенков окрашенных фасадов, а не измеренный цвет производителя или код RAL/NCS. Фото содержат освещение, тени и баланс белого; исходный цвет нельзя достоверно восстановить пипеткой. Для точного совпадения нужен физический образец или спецификация производителя.

Материалы используют существующий PBR-проход, metalness = 0 и матовую поверхность. Оттенок и превью задаются одним sRGB значением; проявление света зависит от геометрии и студийного окружения. Текстуры камня со снимка кухни и рисунки фасадов в этом обновлении не добавляются. Изображения — только исходные референсы, в браузер не загружаются.

Авторитетное определение: `src/three/materials/materialRegistry.ts`. Допуски слотов воспроизводятся генераторами `assets/source/wardrobes-integration/generate_runtime.py` и `assets/source/dressers-integration/generate_runtime.py`. Сохранённые материалы и значения по умолчанию не меняются.
