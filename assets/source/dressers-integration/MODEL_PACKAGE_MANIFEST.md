# Пять комодов — облегчённый model-only пакет v2

Дата: 20.09.2026. Замена первоначального review ZIP моделей 10–14. Начать с **DRESSERS_10_14_INTEGRATION.md**: инструкция содержит пути, регистрацию, общие материалы, формулы UV и критерии приёмки основным чатом проекта.

Геометрия поддерживается входным runtime и проверена. Полная смена покрытий и физически корректный рисунок при resize требуют общей интеграции. Пакет сам не регистрирует мебель в UI и не содержит исправлений общего движка.

Высокое число primitives связано с отдельными деталями, фиксированными скруглениями и поверхностями с разными UV-привязками. В этой версии геометрия не упрощалась; FPS не измерен. Уменьшение пакета достигнуто удалением древесных копий.

## Общие ресурсы

Модели 13/14 используют три уже существующих файла в `public/materials/wood/oak-natural/`: base-color.jpg, normal-gl.jpg, roughness.jpg. Эти JPEG не включены в ZIP повторно. Их URI, SHA256 и проверка находятся в `assets/source/dressers-10-14-shared/`. Все остальные необходимые модельные исходники сохранены.

В v2 нет новых изображений текстур или новых записей material registry. Предложения однотонных покрытий в инструкции — будущие небольшие PBR-записи общей библиотеки. Другие модели уже могут использовать oak-natural. Нейтральные 1×1 карты сохранены; их объём несущественен.

## Что проверено

- 64 теста / 15 файлов PASS в исходном snapshot с пятью комодами, без отдельного пакета шкафа 09; из них 30 тестов моделей 10–14.
- npm run build PASS, исходное предупреждение JS bundle >500 kB.
- Все GLB: 0 errors / 0 warnings; у 13/14 по три ожидаемых infos URI_GLB.
- Реальные внешние JPEG, SHA256, относительные пути, отказ при отсутствии карт.
- Геометрические bufferViews, узлы, meshes, материалы, samplers, конфиги и resize contracts совпадают с v1; все пять GLB воспроизводятся побайтно.
- Четыре заново полученных CPU изображения base/max у 13/14 попиксельно совпали с v1. Все девять production preview states пяти моделей совпали.
- Сохранены все 55 прежних превью/листов и 10 референсов. Другие состояния повторно не рендерились, так как геометрия и данные состояний не изменились.
- Affine UV: REQUIRES_ENGINE_EXTENSION. Browser WebGL, Blender export/reimport, GPU FPS не выполнялись. Скрипты воспроизведения и ограничения приложены.

## Происхождение

Исходный проект: `furniture-3d-configurator под архив.zip`, SHA256 `44e694f98e4d5a300d1e40ce55188166c6144c690491dc66c5d10a9b95d0cd3a`.
Предыдущий пакет комодов: `furniture-3d-configurator-dressers-10-14-review.zip`, SHA256 `41849a1312d957e108d867bbc012b311e14fe2d8c5da295ff92a18cb729801be`.

В архиве только модельные пути, общие для этой партии отчёты и документация. Корневые зависимости проекта, registry, controllers, node_modules, dist, .git, прошлые столы/шкафы и дубли древесных карт исключены. `MODEL_PACKAGE_FILES.sha256` содержит SHA256 каждого файла, кроме самого списка.

Габариты взяты из пользовательских референсов; скрытые размеры и диапазоны отмечены как проектные оценки. У №10 общая глубина 350 мм, глубина корпуса трактуется как 330 мм. Оси/единицы и правила из прежнего пакета сохранены. Интерактивное открывание и изменение числа деталей остаются отдельными функциями проекта.
