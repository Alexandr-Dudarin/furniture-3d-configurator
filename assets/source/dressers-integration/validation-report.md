комодов v2 проверен по 255 SHA256-записям. Пять GLB перенесены побайтно;
существующие модели, карты PBR и превью материалов также не изменены.

Браузер: Chromium, программный WebGL. Проверялась реальная production-сборка
с диагностическими globals только в QA-варианте. GPU-счётчики снимались после
отрисовки, а не до первой загрузки геометрии. Их стабильность не является
замером всей памяти процесса. FPS на физическом телефоне не измерялся.
Скриншоты находятся в previews/, подробные измерения — browser-report.json.

Основной JS: 256.14 kB / gzip 75.83 kB. Отложенная сцена: 647.84 kB /
gzip 165.18 kB. Пять новых runtime chunks: 92.33–143.11 kB до gzip.
Прежнее предупреждение Vite о размере 3D chunk сохраняется. Порог не повышен;
разрешение текстур и геометрия ради оптимизации не уменьшались.

Общий npm run lint не заявляется полностью чистым: в прежних файлах были
замечания, а авторские review-тесты/preview exporters используют explicit any.
Они сохранены как часть исходного модельного пакета. Изменённый production-код,
новые каталоги/UV/runtime и новый integration test проходят ESLint отдельно.

Авторские validation-report и runtime-compatibility.json в папках моделей
описывают этап передачи, включая ограничение legacy UV API. В актуальном
приложении используется общий affine runtime с отдельной проверкой по вершинам.
Анимация открытия, изменение числа ящиков/полок и физические нагрузки в этот
этап не входят. Следующая функция — открывание подготовленных дверей/ящиков.
