# Studio scene v1 — проверка

Дата: 20 сентября 2026. Основа: modular tables v6 + UI polish v1.
До изменений восстановленная основа прошла проверки 173/173 и 4/4.

- Vitest: **186 тестов / 20 файлов — PASS**, включая 3 новых теста владения
  ресурсами и освобождения окружения.
- TypeScript + production Vite build: **PASS**. Итоговый JS 878.48 kB,
  gzip 235.56 kB; CSS 11.05 kB, gzip 3.04 kB.
- ESLint всех изменённых TS/TSX: **PASS**.
- Общий `npm run lint`: 11 прежних ошибок в неизменённых файлах:
  по 5 `no-explicit-any` в export_preview_states.ts моделей 05/06 и
  `set-state-in-effect` в CustomSelect.tsx. Они не исправлялись в этой поставке.
- Предупреждение Vite о chunk >500 kB сохранено; разделение кода вынесено
  в следующий отдельный этап оптимизации.

## Реальный браузер

Chromium 153 / WebGL через программный SwiftShader. Проверено настоящее
React-приложение с GLB и PBR-картами. Скриншоты просмотрены.

- Все 6 готовых моделей последовательно переключаются через интерфейс.
- Все 5 оснований сборки загружены; в сцене остаётся одна мебель.
- UUID окружения и положение камеры сохраняются при переключении моделей.
- Проверены белый/чёрный мрамор, светлый камень, дуб, орех и три варианта металла.
- Максимальная сборка 200 × 100 см, основание 84 см, толщина 50 мм:
  нижняя отметка 0, верхняя 0.89 м, все углы габарита внутри камеры теней.
- Ввод высоты 64 см, смена покрытия и перезагрузка сохраняют конфигурацию.
- Камера не опускается под пол; расстояние ограничено 5 м.
- Для ширины экрана 320/390 px максимальная столешница помещается в кадре:
  крайние вершины занимают до 91.35% половины ширины, положение камеры неизменно.
  При возврате на широкий экран возвращается прежний угол 45°.
- На сравнимых сборках число вызовов рисования не выросло (например 19/21/41);
  число GPU-текстур увеличилось на одну — карту окружения.
- Ошибок JS/шейдеров не получено. Дополнительный инспекционный импорт Three.js
  в первом QA-сценарии вызвал предупреждение о второй копии; это импорт тестового
  сценария, в приложение он не входит. Финальная мобильная проверка — без предупреждений.

Это проверка функциональности и изображения, не замер скорости на реальном
мобильном GPU. FPS, стартовую задержку и бюджет памяти нужно измерить отдельно.
Ни один GLB, PBR-файл, контракт размеров или формат сохранений не изменён.
