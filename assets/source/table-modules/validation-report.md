# Проверка модульных столов v1 — 19.09.2026

## Автоматические проверки

- Полный набор Vitest: **90 тестов в 15 файлах, успешно**.
- TypeScript и production build Vite: успешно.
- ESLint изменённых TS/TSX-файлов: успешно.
- glTF Validator: у обоих оснований 0 errors, 0 warnings.
- У каждого основания 1 информационное сообщение `NODE_EMPTY`: attachment node без геометрии.

Геометрические проверки охватывают все семь форм, промежуточные и крайние
размеры, три толщины. Проверяются внешние габариты, замкнутость геометрии,
направление треугольников, ненулевая площадь граней, нормали, метрический масштаб
UV сверху, снизу и на вертикальном торце, неизменный радиус углов и размеры срезов.

Integration-тесты используют отдельные production GLB оснований. Проверяются
неподвижный footprint, контакт с полом, attachment, размеры колонны/диска/монтажной
пластины, изменение высоты, освобождение старой геометрии, независимая смена
материалов основания и стабильные UV/texture transforms столешницы.

Проверки состояния охватывают совместимость модулей, диапазоны, круг с единым
диаметром, миграцию localStorage v1 → v2, чтение старых ссылок, ссылки сборок,
отдельную память режимов и независимый сброс. Старые тесты готовых моделей
и UV также проходят.

## Браузерная проверка

Chromium 153, программный WebGL, desktop 1440×1000 и компактное окно 900×650:

- восстановление старого круглого стола Ø130 см из localStorage v1;
- семь вариантов формы и изменение размеров;
- недоступность реечного основания для круга и переход на совместимую опору;
- толщина 35 мм, высота основания 77.8 см, итоговая высота стола 81.3 см;
- независимый белый мрамор столешницы и белый металл основания;
- перезагрузка с сохранением сборки;
- реальное копирование ссылки через Clipboard API;
- открытие ссылки в чистом браузерном контексте;
- возвращение к готовой модели с прежними размерами;
- сброс сборки без сброса готовых моделей;
- прокрутка панели, выбор материала и доступность кнопок в компактном окне.

Ошибок JavaScript и сообщений console.error в этих сценариях нет.
Снимки `previews/rounded-slat.png` и `previews/round-fluted-tall.png` получены
из работающего приложения и просмотрены после тестирования.

Предупреждение Vite о размере общего JS chunk >500 kB сохраняется от предыдущего
этапа; оно не препятствует сборке. Проверка не является расчётом прочности мебели.
