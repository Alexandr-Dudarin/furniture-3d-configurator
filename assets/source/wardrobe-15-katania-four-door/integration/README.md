# Проверка интеграции

Актуальный отчёт: `docs/wardrobe-15-katania-v1-validation.md` от корня проекта.

- `test.txt`, `build.txt`, `lint.txt` — результаты команд.
- `reproduction.json` — повторная генерация и сохранность прежних public assets.
- `browser-report.json` — состояние, габариты, двери, счётчики renderer и скачивания.
- `png-verification.json` — декодирование и размеры PNG.
- `previews/` — изображения из реальной WebGL-сцены и мобильного интерфейса.

Это результаты интеграции поверх configuration-export-v1. Отчёты на уровень
выше описывают первоначальное создание модельного пакета.
