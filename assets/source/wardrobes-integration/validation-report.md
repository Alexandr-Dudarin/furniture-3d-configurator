# Отчёт интеграции шкафов 07–09

21 сентября 2026. Основа — принятый пользователем Loading v1.

## Входящие модели

Использованы три GLB из присланных review-пакетов, геометрия не пересоздавалась.
Проверены original source contracts и материал-targets. Исходные отчёты
Khronos Validator содержат 0 errors / 0 warnings. Их исторические статусы
`REQUIRES_ENGINE_EXTENSION` относятся к preview config, а не к новой
production-обвязке.

## Автоматические проверки

- Полный Vitest: **224 tests / 29 files PASS**.
- Сохранены 19 проверок исходных шкафов: крайние/комбинированные размеры,
  миллиметровая точность, толщина плит, зазоры, стыки, pivots, hardware и возврат.
- Новые integration-тесты на трёх настоящих GLB сравнивают все UV-вершины
  панелей с физической длиной поверхности и дугой кромки после изменения размеров
  и нескольких замен finishes. Repeat/offset всех PBR-карт совпадают;
  повторные refresh не накапливают изменения. Ошибка < 1e-6 UV.
- Камера проверена по восьми углам максимального габарита в широком и узком кадре.
- Проверены алиасы карт roughness/metalness/emissive, независимость ресурсов,
  неединичный исходный repeat/offset и отклонение неоднозначного UV-контракта.
- `npm run build` PASS. Предупреждение о большом отложенном Three.js chunk осталось.
- ESLint на новых и изменённых файлах приложения PASS. Полный `npm run lint`
  сохраняет **11 прежних ошибок**: 10 no-explicit-any в source-экспортёрах столов
  05/06 и 1 set-state-in-effect в CustomSelect. Новых lint-ошибок не добавлено.

При одновременном запуске test/build/lint один тяжёлый прежний тест
capsule/bullnose превысил лимит 5 секунд. Отдельный запуск всего набора проверяет
финальный результат без конкурирующей сборки; timeout в тестах не повышался.

## Chromium / настоящий WebGL

Проверка production-сборки с диагностическим доступом к store/runtime:

1. При открытии стола не запрашиваются GLB и runtime chunks шкафов.
2. Все три шкафа: базовое состояние, ввод размеров в мм, максимальный габарит,
   белый корпус + деревянные фасады, независимая смена материалов.
3. Модель помещается в кадр; изменение её размеров не меняет камеру.
4. Reload, сброс модели и ссылка восстанавливают ожидаемые настройки.
5. Возврат к сборщику стола восстанавливает его камеру.
6. Мобильный viewport 390 × 844, без горизонтального переполнения.
7. Ошибка загрузки runtime chunk восстанавливается перезагрузкой с сохранением выбора.
8. Два цикла трёх шкафов и первого стола: число геометрий/текстур повторяется;
   прежняя модель освобождается, одновременно остаётся одна группа мебели.
9. Все шесть готовых столов загружаются после шкафов.
10. Поздний ответ GLB при переходе к сборщику не добавляет лишнюю модель в сцену.

Необработанных ошибок страницы: 0. Подробности — `browser-report.json`,
`lifecycle-report.json`; изображения — `previews/`.

Числа GPU-ресурсов включают общую сцену и её окружение. Большое число вызовов

Это измерение структуры рендера, не FPS-бенчмарк на устройстве пользователя.
