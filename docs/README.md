## Как читать историю этапов

Документы с названиями `*-v1`, `*-v2` и `*-validation` описывают конкретный
этап разработки. Их даты, количество тестов, замеры, ограничения и списки
«что дальше» относятся к тому этапу. Более позднее изменение может их
дополнять или заменять; текущий статус собран в README и дорожной карте.

Некоторые старые отчёты ссылаются на `docs/updates/` — локальные инструкции
переноса файлов и коммита. Эта папка не публикуется и для запуска проекта не
нужна. Актуальные команды доступны в [deployment.md](deployment.md).

[Подготовка публикации 1 октября 2026 года](publication-ready-v1.md) сохранена
как исторический отчёт. Для работы с опубликованным проектом используйте
текущую инструкцию развёртывания.
