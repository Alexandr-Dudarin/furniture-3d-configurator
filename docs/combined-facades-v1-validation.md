# Проверка «Рифлёных краёв» — 24 сентября 2026

Обновление поверх принятого `facade-lighting-v1`. Проверки проведены в Linux,
Node.js, Vitest и Chromium с программным WebGL (SwiftShader).

## Автоматические проверки

| Проверка | Результат |
| --- | --- |
| Полный набор Vitest | 45 файлов, 398 тестов — PASS |
| Финальный запуск геометрии после расширения проверки UV | 10 тестов — PASS |
| TypeScript и production-сборка (`npm run build`) | PASS |
| ESLint изменённых TS/TSX-файлов | PASS |
| Согласованность source JSON и runtime-каталогов | 9 из 9 моделей — PASS |

Проверки включают геометрически замкнутые панели без вырожденных треугольников,
габариты и монтажные плоскости, постоянные шаг/ширину/глубину канавок,
симметричные целые повторения, гладкую середину и метрические UV.
Раскладка дополнительно проверена на последовательности ширин 294–1000 мм
с разными полями. Проверены контакт ручек с фасадом, подвижные группы,
сохранение и восстановление конфигураций всех девяти моделей.

У сборки остаётся прежнее предупреждение о размере отложенного 3D-чанка
более 500 КБ; ошибок сборки нет. Зависимости приложения не менялись.

## Проверка в браузере

- Все четыре шкафа и пять комодов: выбор нового рисунка в интерфейсе,
  белые фасады, размеры min/base/max — 27 сочетаний.
- «Бруклин»: зелёное покрытие, открытые ящики, изменение ширины при
  сохранении состояния открывания.
- «Челси»: дубовые фасады и открытые двери; переключение «Наполнение»
  скрывает процедурные двери, возврат восстанавливает их.
- «Байкал»: смена покрытия, перезагрузка с локальным сохранением,
  восстановление по ссылке после очистки локального хранилища, сброс модели.
- Мобильная панель на ширинах 390 и 320 CSS-пикселей: карточка доступна,
  выбирается, горизонтального переполнения страницы нет.
- Реальная кнопка «Сохранить вид в PNG» скачивает изображение текущей модели
  без панели управления; сохранённое изображение просмотрено.
- В выполненных сценариях нет ошибок JavaScript и HTTP-запросов приложения.

Первый браузерный сценарий завершил проверки моделей и 390 px, затем
остановился на неоднозначном текстовом локаторе теста для 320 px: название
рисунка встречалось в нескольких элементах интерфейса. Локатор уточнён;
отдельный повторный сценарий 390/320 px и кнопки PNG прошёл полностью.

## Установка

В архив входит `scripts/check-combined-facades-v1.cjs`: проверка хешей новых
файлов и принятой базовой версии. Ожидаемый итог:
`COMBINED_FACADES_V1_FILES_CONFIRMED`.

После распаковки пользователь проверяет рисунок, покрытия, размеры и
открывание в своей среде. Коммит выполняет пользователь после проверки.
