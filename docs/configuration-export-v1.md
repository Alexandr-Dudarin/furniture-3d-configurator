# Сводка конфигурации и PNG v1

22 сентября 2026. Все готовые модели и сборные столы получают раздел «Ваш
вариант»: выбранная модель/сборка, размеры с единицами, фактические покрытия.
У сборных столов отдельно указаны основание, форма, кромка, толщина,
высота основания и итоговая высота. Круг показывает диаметр.

«Копировать описание» копирует сводку со ссылкой. Если Clipboard API
недоступен, появляется текстовое поле для ручного копирования.
Существующие копирование ссылки, сброс и автосохранение сохраняются.

«Сохранить вид в PNG» скачивает текущий 3D-ракурс без интерфейса, со студийным
фоном, материалами и текущим положением дверей/ящиков. Размер — текущий
рендер-буфер просмотра, с действующим пределом DPR 2. Изображение не меняет
камеру, пропорции или настройки. Если объект пользователь обрезал ракурсом,
на снимке он тоже будет обрезан. На телефоне сохраняется область 3D-просмотра.

Ссылка передаёт конфигурацию изделия; ракурс, режим «Наполнение» и положения
дверей/ящиков остаются состоянием просмотра и не добавлены в формат ссылки.

## Реализация

Лёгкий `pngExportStore` связывает UI с отложенно загружаемой сценой. Кнопка
доступна только для той конфигурации, чьи модель и покрытия действительно
применены. Завершение устаревшего запроса не включает экспорт нового выбора.
Повторное нажатие блокируется на время кодирования, ошибки дают возможность
повторить. Нет `preserveDrawingBuffer: true`: один дополнительный render и
`canvas.toBlob` выполняются в одной задаче. Object URL освобождается после
передачи браузеру. Новых зависимостей нет.

## Покрытия

Тёмно-зелёный матовый и пудрово-бежевый матовый доступны для корпуса и фасадов
трёх шкафов и пяти комодов. Существующие настройки и значения по умолчанию
не заменяются. Оттенки приближены к фото, не являются точным заводским кодом.
Источники и параметры: [reference-colors/README.md](../assets/materials/reference-colors/README.md).

## Проверка пользователем

- Открыть «Ваш вариант» у стола, шкафа и комода, сравнить размеры и материалы.
- Скопировать описание, открыть содержащуюся в нём ссылку.
- Выбрать новые цвета корпуса и фасадов, обновить страницу и проверить ссылку.
- Повернуть мебель, открыть дверь/ящик или выбрать наполнение шкафа,
  скачать PNG и проверить изображение. Повторить на телефоне.
- Быстро сменить модель или покрытие: PNG доступен после применения выбора.

Стандарт обновлён до v2.8: раздел 40 описывает подготовку сменных фасадов.
Переключение рисунка фасада будет отдельным этапом.
