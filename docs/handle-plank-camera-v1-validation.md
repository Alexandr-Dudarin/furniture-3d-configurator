# Проверка handle-plank-camera-v1

Дата: 29 сентября 2026. База: установленный и принятый пользователем
`furniture-handles-fit-v1` (v2.30). Перед правкой старый checker подтвердил
19/19 файлов этапа и 950/950 файлов базы.

## Выполнено

- `npm test -- --testTimeout=60000 --maxWorkers=2`: **596 тестов, 68 файлов**,
  все прошли; 102,14 с. Дополнительно после уточнения типа снятия блока ящиков
  повторён `cameraClearance.test.ts`: 9/9.
- `npm run build`: TypeScript и Vite прошли. Предупреждение о chunk > 500 kB
  осталось; сборку не останавливает. Новых зависимостей и GLB нет.
- ESLint 11 затронутых TS/TSX-файлов: без ошибок.
- Raycast по действительным треугольникам планки: корень касается Z=0;
  обе стенки 12 мм, открытое место для пальцев, нет части позади фасада.
  Проверены длины 110/170 мм и панели 16/18 мм.
- Ящики гардеробной: 35 мм от верхнего края, контакт с фасадом и выступ,
  два положения по глубине, крайние ширины/глубины/высоты рядов;
  габариты, полезный объём, сохранение открытия при смене ручки.
- Все четыре production GLB шкафов: посадка на видимый рамочный фасад,
  размеры 110/170 мм, отступы, отсутствие пересечения соседних ручек,
  минимальные/максимальные размеры, материалы, открытия, режим наполнения,
  восстановление исходных ручек и освобождение геометрии.
- Камера: быстрое перемещение через весь корпус, вход сбоку/сзади/сверху,
  близкий осмотр и панорамирование вдоль фасада, углы ближней плоскости
  при разных aspect, выдвижение ящика перед камерой, перекрывающиеся объёмы,
  отсоединение от каталога, «Показать всю сборку», неподвижное состояние
  без повторных корректировок. Использован реальный OrbitControls.
- Реальная сборка со штангой и ящиками: заполненные границы ящика соответствуют
  его геометрии в закрытом/открытом положении, следуют изменению глубины и
  освобождаются при удалении ящиков/сборки.
- Техническая проекция сечений построена из фактических треугольников Three.js
  и визуально осмотрена. Это иллюстрация геометрии, не WebGL-скриншот.

## Границы проверки

В этой среде не выполнены проверка WebGL браузером, замеры FPS на ноутбуке/
телефоне, реальные жесты и визуальная проверка PNG. Математические проверки
не подтверждают субъективное удобство нового предела приближения. Короткий
сценарий пользовательской приёмки приведён в `handle-plank-camera-v1.md`.
