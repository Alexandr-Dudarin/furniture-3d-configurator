# Проверка motion-antialiasing-v1

26 сентября 2026 года. Подготовлено поверх принятого
wide-herringbone-dressers-v1 revision 1.1. Node.js 24.19.0.

## Выполнено

- `npm test -- --testTimeout=60000`: **51 файл, 450 тестов прошли**.
  Финальный запуск — 41,68 с. Начальный запуск выявил старое ожидание
  herringbone-wide у «Норда»; тест переведён на оставшуюся обычную ёлочку,
  сохранив проверки геометрической симметрии и resize при открытых ящиках.
- `npm run build`: TypeScript и Vite прошли.
- ESLint всех изменённых файлов TypeScript прошёл. Полный исторический
  lint проекта в этом этапе не заявляется пройденным.
- Сборка по-прежнему разделена: основной JS 290,93 кБ (gzip 81,53 кБ),
  отложенный SceneView 682,13 кБ (gzip 178,01 кБ), отдельные runtime моделей.
  Предупреждение Vite о chunk >500 кБ сохраняется, его порог не повышен.

Новые проверки охватывают адаптацию 4 → 2 → 1 и постепенное восстановление,
игнорирование пауз/одиночных задержек, симметрию фаз, сброс суммы при новом
кадре и переходе к неподвижному уточнению. Проверены нормировочные коэффициенты
для 2/4/16 образцов, восстановление проекции и render state после исключения,
экспорт без старой суммы, ограничения памяти/float attachments и освобождение
буферов. Это тесты логики с подменой WebGLRenderer, а не замеры реального GPU.

Каталожные тесты проверяют переход старых сохранений «Норда» на обычную ёлочку
с сохранением размеров и материалов. Снятый ID отсутствует в выборе.

## Ещё не подтверждено

Визуальная приёмка на ноутбуке и телефоне остаётся открытой. Локальный Vite
запускался на 127.0.0.1:5173, но удалённый браузер среды вернул
ERR_BLOCKED_BY_CLIENT при открытии этой страницы. Поэтому здесь нет нового
скриншота, проверки WebGL-шейдеров в браузере, измерений FPS/нагрева или
подтверждения, что муар полностью исчез. Скачивание браузера для локальной
проверки тоже не завершилось успешно; это не тест приложения.

Сценарий проверки, сравнение с одним проходом и диагностические показатели
описаны в [motion-antialiasing-v1.md](motion-antialiasing-v1.md).
Для приёмки важны отсутствие следов при движении, читаемость рельефа,
плавность управления и неизменная яркость материала/PNG.

Публикация, коммит, тесты на физическом телефоне и изменение тарифов хостинга
в рамках подготовки пакета не выполнялись.
