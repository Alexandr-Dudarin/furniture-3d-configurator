# Проверка wardrobe-drawer-handles-v1

29 сентября 2026. База — принятый и закоммиченный wardrobe-drawer-placement-v1.
До изменения checker подтвердил 13/13 файлов этапа и 940/940 файлов базы.

## Результаты

- Полный `npm test -- --testTimeout=60000 --maxWorkers=2`: **558 тестов,
  65 файлов — успешно**, 97,00 с. Добавлено восемь тестов в двух файлах.
- Целевой прогон новых проверок и сохранения гардеробной: 23 теста / 3 файла
  успешно, 3,47 с.
- `npx tsc -b` и `npm run build`: успешно.
- ESLint всех изменённых TS/TSX: без замечаний.
- Генератор гардеробной остаётся ленивым chunk: 8,15 kB / 3,60 kB gzip.
  SceneView: 697,57 kB / 182,82 kB gzip. Прежнее предупреждение о размере
  chunk > 500 kB сохранено, порог не менялся.
- Новых зависимостей, GLB, текстур и проходов рендера нет.

## Что проверено

- Отсутствующее поле ручки и каждый из вариантов bar/knob/none проходят
  сохранение и ссылку v4 без коррекции. Некорректные значения сбрасываются
  с уведомлением, остальные параметры остаются прежними.
- Смена формы не требует подтверждения и не сдвигает ручные полки/штангу.
  Настройки остаются у своей секции при перестановке, изменении глубины,
  количества/высоты рядов, положения фасадов и переключении режима.
- Текстовое описание различает форму и материал. Для «Без ручек» не показан
  материал несуществующей ручки; покрытие направляющих указано отдельно.
- Реальные Three.js-объекты: все три формы, оба положения фасадов,
  ширины 40/100 см, глубины 40/80 см и ряды 20/30 см. Крепления примыкают
  к фасаду, ручки не выходят за его контур по ширине/высоте, стык короба
  сохранён. Физический Box3 совпадает с расчётным полным закрытым габаритом.
- Старый вариант без поля handle имеет тот же план геометрии, что явная скоба.
  Повторная смена формы при половинном открытии не меняет положение фасада
  и степень открытия; движущиеся детали сохраняют один ID.
- В варианте без ручек их геометрия отсутствует. Настоящий raycast попадает
  в фасад и находит правильный ящик. Reduced motion завершает открытие сразу.
- Одинаковые ручки используют общие геометрию и материал. Снятая геометрия
  освобождается один раз; при повторной смене не происходит утечки/двойного
  dispose. Материал сохраняется на направляющих без повторной загрузки.
- Лимит 6: действие добавления не создаёт 7-ю секцию. Из импортированных
  26 секций остаются первые 6, и в сессии/ссылке появляется объяснение.
  Повторное чтение уже допустимой сборки не выдаёт уведомление.
- Все прежние тесты каталога, фасадов, компоновки, открытия, хранения,
  интеракций и экспорта прошли в полном прогоне.

Число 25 зафиксировано как будущий общий предел, не как протестированная
в этом этапе вместимость сцены. Измерения FPS, нагрева, памяти на физическом
ноутбуке/телефоне не проводились.

Присланные скриншоты предыдущего этапа просмотрены. Визуальная проверка новых
ручек в браузере, реальный PNG и касания здесь не выполнялись: локальный браузер
недоступен. Проверки Three.js выполнялись без растеризации кадра. Сценарии
для устройства пользователя находятся в [описании этапа](wardrobe-drawer-handles-v1.md).
