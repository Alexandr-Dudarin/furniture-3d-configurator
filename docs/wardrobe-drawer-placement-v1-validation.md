# Проверка wardrobe-drawer-placement-v1

29 сентября 2026. База — принятый и закоммиченный wardrobe-drawers-v1.
До изменений его checker подтвердил 21/21 файлов этапа и 928/928 файлов базы.

## Результаты

- Полный `npm test -- --testTimeout=60000 --maxWorkers=2`: **550 тестов,
  63 файла — успешно**, 68,31 с. Добавлено восемь проверок в двух файлах.
- Отдельный прогон новых проверок: 8/8 успешно.
- `npm run build`: TypeScript и production build — успешно.
- ESLint всех изменённых TS/TSX — без замечаний.
- Генератор гардеробной остаётся отдельным ленивым chunk: 7,85 kB / 3,47 kB
  gzip. SceneView — 697,57 kB / 182,82 kB gzip. Прежнее предупреждение о
  chunk > 500 kB сохраняется; порог не повышался.
- Новых зависимостей, текстур и GLB нет. Пакет содержит только изменённые
  исходники, проверки, стандарт, описание и инструкции.

## Проверенные свойства

- Старые сборки без placement и явные значения recessed/flush проходят
  сессию и ссылку без изменений и уведомлений. Неверное значение корректируется
  с уведомлением; не теряются остальные параметры.
- Переключение не меняет ручные высоты наполнения, материалы и количество
  ящиков, не вызывает подтверждение. Изменение количества/высоты рядов и глубины
  сохраняет выбранное положение; сброс удаляет блоки согласно прежним defaults.
- Все комбинации ширины 40/100 см, глубины 40/80 см, ряда 20/25/30 см,
  обоих положений и четырёх ящиков: плоскость фасада, примыкание боковин/дна,
  задний зазор, выступ ручки, толщина и перекрытие направляющих корректны.
- Старая геометрия без placement идентична явно утопленной геометрии.
- Реальные объекты Three.js в смешанной сборке: физический Box3 совпадает
  с объявленными закрытыми габаритами, включая выступающие ручки. Общая задняя
  плоскость сохраняется; выступ мелкой секции не добавляется к глубокой.
- Повторные переключения положения при половинном открытии сохраняют объекты
  деталей, степень открытия и стык фасада с коробом; смещение не накапливается.
  После закрытия фасад попадает в выбранную плоскость, движение завершается.
- Описание конфигурации отдельно показывает глубину корпуса, полный закрытый
  габарит с ручками и положение фасадов каждого блока.
- Остальные проверки каталога, наполнения, движения, интеракций, хранения
  и экспорта прошли в полном прогоне.

Изображения пользователя использованы для понимания желаемой передней плоскости.
Интерактивная проверка в реальном браузере, PNG и касания на телефоне здесь
не выполнялись: локальный браузер недоступен. Тесты Three.js проверяют геометрию
и движение без растеризации кадра. Порядок визуальной проверки находится в
[описании этапа](wardrobe-drawer-placement-v1.md).
