# Проверка wardrobe-filling-placement-v1

29 сентября 2026. База — принятый и закоммиченный wardrobe-layout-v1.
До изменения checker подтвердил 17/17 файлов этапа и 923/923 файла базы.

## Результаты

- Полный `npm test -- --maxWorkers=2 --testTimeout=60000`: **59 файлов,
  529 тестов — успешно**, 68,75 с.
- `npm run build`: TypeScript и production build — успешно.
- ESLint всех изменённых TS/TSX — успешно, без замечаний.
- Архив — только изменённые файлы и инструкции. Новых зависимостей, GLB
  и текстур нет. SceneView ~697,15 kB; прежнее предупреждение о размере
  chunk сохраняется, порог не менялся.

## Проверенные регрессии

- Просвет 214 мм над дном и 584 мм между полками сопоставлен с фактическими
  поверхностями панелей в плане геометрии Three.js, включая толщину 16 мм.
- Полка 220 см в секции 280 см остаётся на месте при включении штанги;
  ось штанги на 210 см. Несколько других высот дают тот же принцип без диалога.
- Полки 215/245 см остаются на месте при добавлении до четырёх. Новые детали
  находятся ниже. Проверены свободные интервалы сверху и между старыми полками.
- В тесном интервале подбор первой новой позиции сохраняет место для всех
  оставшихся добавлений, а не только для одной ближайшей полки.
- Перебор всех допустимых пар ручных полок на сетке при высотах 120/160/280 см:
  независимый проход по доступным координатам проверяет вместимость. Если
  добавления помещаются, старые позиции сохраняются без подтверждения.
- Если добавления не помещаются вокруг старых позиций, preview требует
  подтверждения; отказ оставляет сборку прежней, подтверждение применяет
  допустимую конфигурацию. Сохранены проверки уменьшения высоты и 150/120 см.
- Верхняя/нижняя полка добавляются к существующей штанге с сохранением её оси
  и старой полки, когда это возможно.
- Неявное удаление полок при включении штанги требует подтверждения,
  даже если оставшаяся полка не перемещается. Явное уменьшение числа полок
  само по себе не порождает дополнительного вопроса.
- Сохранение и ссылка v4 восстанавливают новые расположения без корректировок
  или потери индивидуальных материалов.

В первоначальном целевом прогоне обнаружена тестовая подготовка, включавшая
штангу с удалением трёх полок без подтверждения. Она обновлена под явное
подтверждение; проверка сохранения и освобождения материалов осталась прежней.
После этого полный набор тестов прошёл.

Скриншоты пользователя просмотрены. Интерактивная проверка исправленного UI
в реальном браузере, PNG и FPS на ноутбуке/телефоне здесь не выполнялась.
Сценарии визуальной приёмки находятся в
[wardrobe-filling-placement-v1.md](wardrobe-filling-placement-v1.md).
