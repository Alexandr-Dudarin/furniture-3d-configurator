# Проверка wardrobe-layout-v1

29 сентября 2026. База — принятый и закоммиченный wardrobe-section-materials-v1.
До правок checker базы подтвердил 15/15 файлов обновления и 920/920 файлов базы.

## Результаты

- Целевой прогон состояния, сохранений, геометрии и описания: **6 файлов,
  70 тестов — успешно**.
- Полный `npm test -- --run --maxWorkers=2 --testTimeout=60000`: **58 файлов,
  520 тестов — успешно**, 70,78 с.
- `npm run build`: TypeScript и production build — успешно.
- ESLint изменённых TS/TSX — успешно, без замечаний.
- Новых зависимостей, GLB и текстур нет. Генератор гардеробной сохраняет
  ленивую загрузку (~5,30 kB). SceneView ~697,15 kB; прежнее предупреждение
  о размере chunk остаётся, порог не увеличивался.

## Что проверено

- Старые автоматические формулы, явное включение/отключение ручного режима;
  отсутствие скрытого удаления полок при включении.
- Сетка 5 см, крайние высоты секции 80–280 см, оба вида наполнения, количество
  полок 0–6, повторная нормализация; недостаточная вместимость сетки.
- Независимое перемещение, отклонение пересечений, неверного индекса, координат
  вне сетки/границ; фактические свободные зазоры и минимальная высота штанги.
- Сохранение абсолютных позиций при росте корпуса; preview, отмена и
  подтверждение перестановки при уменьшении и смене наполнения.
- Неверные/крайние импортированные координаты, уведомления, сохранение/URL v4,
  отсутствие записи неподтверждённых изменений, текстовое описание, reset.
- Материалы, стабильные ID при перестановке, автоматическое наполнение
  новой секции; сохранение независимых настроек остальных режимов.
- Фактические поверхности Three.js-моделей: все 21 значения высоты,
  поперечная/торцевая штанга при глубинах 40/45/55 см, допустимые количества
  полок, размер креплений, положение дна/верха и зазоры.
- Ручная штанга на 150 см и полка с нижней поверхностью на 170 см;
  неизменность габаритов корпуса, боковин, геометрии, UV и объектов материалов
  при перемещении наполнения.

Эти проверки не заменяют визуальную приёмку в браузере. Управление мышью/
касанием, диалог, внешний вид PBR, PNG, FPS и память ноутбука/телефона
автоматически не проверены. Сценарии приёмки:
[wardrobe-layout-v1.md](wardrobe-layout-v1.md).
