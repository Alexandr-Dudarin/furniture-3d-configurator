# Проверка wardrobe-refinements-v1

28 сентября 2026. База восстановлена из выданных пакетов relief-filter-v1 и
wardrobe-assembly-v1. До изменений checker подтвердил 24/24 файлов этапа и
903/903 файлов совместимой базы.

## Выполнено

- Целевой прогон: 5 файлов / 27 тестов, все прошли.
- Полный прогон `npm test -- --testTimeout=60000 --maxWorkers=2`:
  **57 файлов / 496 тестов**, все прошли, 48,75 с.
- `npm run build`: TypeScript и production build успешны.
- ESLint изменённых TS/TSX: без ошибок и предупреждений линтера.
- Отдельный chunk генератора ~4,85 kB, gzip ~2,31 kB. Зависимости и GLB
  не добавлены, PBR не менялись. Прежнее предупреждение Vite о SceneView
  ~697 kB сохраняется; порог предупреждения не изменён.

## Содержание проверок

- Крайние размеры 80/280 см и глубины 40/80 см проверены по фактическим
  bounds геометрии. Сохраняются толщина плит, пол и общая задняя плоскость.
- Для всех 21 поддерживаемых высот и 9 глубин проверены схемы со штангой
  и без неё, запросы 0/1/2/4/6 полок. Свободные зазоры между панелями
  минимум 20 см, под штангой минимум 60 см, опоры торцевой штанги касаются
  правильной верхней панели и имеют положительную длину.
- Уменьшение секции ограничивает полки; их число не восстанавливается
  неожиданно после увеличения высоты. Включение штанги оставляет верхнюю полку.
- Новые размеры и обе полки со штангой восстанавливаются из сессии и ссылки.
  Сохранённый дуб остаётся дубом; reset даёт серый материал. Сессия v4 и
  формат ссылки не менялись, поскольку структура данных осталась прежней.
- Математическая проекция крайних углов низкой и шестиметровой высокой сборки
  помещается в широкий/портретный кадр после reset. Редактирование размеров
  не меняет расстояние от камеры до цели само по себе.
- Полный прогон включает прежние тесты каталога, PBR, анимаций, сохранений,
  PNG и сглаживания.

## Границы проверки

В этой поставке не выполнен интерактивный браузерный осмотр нового UI/WebGL,
реальный PNG новой конфигурации или touch-проверка. CSS и JSX проверены по
коду, предоставленные пользователем скриншоты использованы для разбора
замечаний. FPS/нагрузка на физических устройствах не измерялись.

Новые цвета кнопок, общее кадрирование и низкие секции нужно проверить
пользователю по сценарию в wardrobe-refinements-v1.md перед коммитом.
