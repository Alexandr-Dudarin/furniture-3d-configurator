# Проверка wardrobe-rod-limits-v1

28 сентября 2026. До изменений предыдущий checker подтвердил 16/16 файлов
wardrobe-refinements-v1 и 913/913 совместимых файлов базы.

- Целевой прогон: 6 файлов / 90 тестов, успешно.
- Полный `npm test -- --testTimeout=60000 --maxWorkers=2`: **57 файлов /
  500 тестов**, успешно, 47,61 с.
- `npm run build`: TypeScript и production build успешны.
- ESLint изменённых TS/TSX: ошибок и предупреждений линтера нет.
- Новых зависимостей и GLB нет. SceneView остаётся ~697 kB; прежнее
  предупреждение о размере chunk сохраняется без изменения его порога.

Проверено: запрет штанг ниже 150 см в нормализации/действиях; ось не ниже
120 см; геометрические зазоры для всех высот 80–280 см и глубин 40–80 см;
создание высокой секции со штангой после низкой; preview без мутации;
отказ применения до подтверждения; неизменность snapshot, сохранения,
ссылки и подписчиков до подтверждения; атомарное применение после него;
отсутствие автоматического возврата штанги; чтение старых сборок/ссылок
с корректирующим уведомлением и сохранением других настроек.

Нативный браузерный диалог, его фокус, Escape, pointer/touch и новый вид
на реальном устройстве автоматически не проверены. UI проверен по коду;
нужна ручная приёмка в браузере по сценарию в wardrobe-rod-limits-v1.md.
500 unit-тестов не подменяют эту проверку.
