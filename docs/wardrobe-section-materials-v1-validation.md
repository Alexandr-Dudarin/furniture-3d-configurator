# Проверка wardrobe-section-materials-v1

29 сентября 2026. База — принятый и закоммиченный wardrobe-rod-limits-v1.
До правок его checker подтвердил 16/16 файлов обновления и 916/916 файлов базы.

## Результаты

- Целевой прогон: 5 файлов, 58 тестов — успешно.
- Полный `npm test -- --testTimeout=60000 --maxWorkers=2`: **57 файлов,
  508 тестов — успешно**, 73,03 с.
- `npm run build`: TypeScript и production build — успешно.
- ESLint изменённых TS/TSX — без ошибок и предупреждений линтера.
- Новых зависимостей, GLB и текстур нет. Генератор гардеробной остаётся
  отдельным ленивым chunk (~5,29 kB). SceneView ~697,15 kB; прежнее предупреждение
  о размере chunk остаётся, порог не увеличивался.

## Покрытие проверками

- независимое наследование корпуса и металла, явный выбор, совпадающий с общим;
- возврат к общему, отклонение чужих/неизвестных ID, повторная нормализация;
- связь покрытия с ID секции, сохранение при перестановке, размерах, наполнении;
- новая секция наследует общие материалы, а не собственные покрытия соседей;
- сохранение/URL v4, старые сборки без ложной коррекции, уведомление при неверном
  материале, фактические материалы секций в текстовом описании;
- сброс гардеробной сохраняет настройки каталога и сборного стола;
- общий объект материала для одинакового finish, назначение всем панелям и
  креплениям нужной секции, сохранение геометрии и метрических UV;
- освобождение материала после последнего использующего его элемента;
- устаревшие загрузки, отмена выбора до завершения загрузки, частичный отказ,
  освобождение поздних материалов и текстур после закрытия сцены.

Общие проверки геометрии и ограничений 150/120 см, зазоров 20/60 см остаются
зелёными. Новые тесты используют программные Three.js объекты и материал-фабрику.
Они не измеряют FPS/память браузера и не подтверждают визуальный вид PBR-карт.

Реальный браузер, ноутбук/телефон и PNG с индивидуальными покрытиями в этом
этапе автоматически не проверены. Ручная приёмка описана в
[wardrobe-section-materials-v1.md](wardrobe-section-materials-v1.md).
